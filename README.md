# gittest

Git 사용법을 익히기 위한 간단한 연습용 프로젝트입니다.

## 목적

- Git의 기본 명령어 실습
- 원격 저장소(GitHub) 연동 연습
- 커밋, 푸시, 풀 등 기본 워크플로우 학습

## 주요 명령어

```bash
# 저장소 초기화
git init

# 원격 저장소 연결
git remote add origin <repository-url>

# 변경사항 스테이징
git add <file>

# 커밋
git commit -m "메시지"

# 푸시
git push -u origin main

# 풀
git pull origin main
```
